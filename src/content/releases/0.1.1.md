## TARP 0.1.1

TARP 是由 AI 主持的桌面跑团应用，支持 Windows x64、macOS Apple Silicon 和 Linux x64。

### 下载

请在下方附件中选择适合系统的安装包：

- Windows：`TARP-0.1.1-windows-x64-setup.zip`
- macOS Apple 芯片：`TARP-0.1.1-macos-arm64.dmg`
- Linux：`TARP-0.1.1-linux-x64-setup.tar.gz`

`stable-*` 文件供应用自动更新使用，手动安装无需下载。`SHA256SUMS.txt` 用于校验下载文件。

### 本次更新

- 增加应用内更新：启动时后台检查新版，也可在「应用设置 → 常规 → 应用更新」中手动检查。
- 支持查看下载进度，更新准备完成后由用户确认重启安装。
- 更新优先使用加速线路，失败后自动尝试备用线路和 GitHub 直连。
- 修复 Windows 安装包图标。

### 开始使用

安装前请查看[入门指南](https://jointarp.party/docs/getting-started/introduction/)。

## v0.1

当前版本号为 `0.1.0`，安装包即将提供。以下说明对应当前开发版本；正式发布后的变更会按版本记录在这里。

### 目前可以做什么

- 载入本地模组，按开局方案选择预设角色，或使用模组提供的制卡流程创建角色。
- 连接模型服务，让 AI 主持查阅规则、处理行动、发起公开检定，并更新本局允许修改的字段。
- 给角色分配 AI 队友，分别选择模型、调整互动主动性，与队友讨论计划或直接 `@` 它。
- 在提供配置的模组中查看自定义世界卡，并嵌入怪物等文档的状态卡片。
- 在冒险里写自己的笔记，内容和未保存草稿按玩家分别保存，并按需要使用语音朗读。
- 用 Markdown、JSON 和 TOML 编写模组资料，配置文档类型、计算字段与 Handlebars 展示模板；冒险文档统一保存为 JSON。
- 从 ZIP、文件夹或 Git 导入模组，并手动同步已有冒险的模组副本，保留本局进度。
- 查看主持与队友的会话上下文，按需手动压缩或启用文档字段订阅。
- 用模组 CLI 校验配置，通过客户端 MCP 创建隔离临时局预演。

操作步骤分别见[第一次冒险](/docs/getting-started/first-adventure/)、[AI 主持](/docs/play/ai-host/)和[模组结构](/docs/modules/structure/)。

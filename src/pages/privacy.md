## 本地数据与模型服务

TARP 在你的电脑上保存应用设置、模型连接凭证、模组、冒险存档和聊天记录，用于运行游戏和恢复进度。你可以管理本地文件；卸载应用不一定会删除这些数据。

当你使用 AI 主持或 AI 队友时，相关对话、角色与模组资料会发送给你配置的模型服务。开启语音朗读时，要朗读的文字会发送给你配置的语音服务。请求可能包含服务所需的账号或 API 凭证，接收方的保存期限和数据用途以其政策为准。使用本地模型时，数据的处理范围取决于你的部署方式。

启用 MCP 模组预演接口并向外部工具提供连接凭证后，该工具能够创建、读取和控制隔离的临时预演冒险，包括其聊天和文档资料。外部工具收到的数据还可能发送给其使用的模型服务，请仅向你信任的工具提供凭证。

## 多人联机

互联网联机需要官方协调服务帮助双方找到彼此。该服务处理房间码、随机连接标识、临时认证凭证、审批状态和连接信令，并使用来源 IP 进行请求限流。连接信令可能包含公网或局域网 IP、端口等网络信息，用于建立双方连接。

协调服务不承载游戏聊天、模组文件、冒险存档或模型密钥。房主主动关闭房间或房间租约到期后，服务清理对应房间记录；连接期间房主会续期。断开连接不会自动删除房主或玩家电脑上的本地数据。

游戏数据通过玩家之间的加密连接传输。房主保存冒险存档，并接收加入玩家的昵称、身份验证信息和游戏操作。获准加入的玩家会接收游戏所需的聊天、状态、模组和图片资料，并可能在本机缓存。当前完整模组缓存可能包含界面中未展示的隐藏资料，因此请只邀请你信任的人加入。

同一局域网内通过地址加入时，不需要官方互联网协调服务，但房主和玩家之间仍会传输游戏数据。

## 网络连接服务与其他第三方

建立互联网直连时，应用会请求第三方 STUN 服务以发现公网地址。被请求的 STUN 服务能够看到请求来源的公网 IP 和端口，联机对方也会收到用于连接的网络地址信息。STUN 服务不承载游戏聊天和模组文件。当前游戏联机使用直连，尚未启用服务器 TURN 中继。

访问官网、检查更新或下载安装包时，相应网站、托管平台或下载平台会接收来源 IP 和必要的请求信息。你通过 GitHub 提交问题或公开诊断信息时，所提交的内容也由该平台处理；请勿附上密钥、私有聊天或未经他人允许的个人资料。

## 保存期限与安全

本地数据由你或房主管理，保存到相应数据被删除为止。发送给模型、语音、STUN、托管或下载服务的数据，由相应服务按其规则处理。

应用的连接诊断只展示状态和数量，不展示完整信令、候选地址或身份密钥。网站、托管和网络连接服务仍可能处理请求信息和运行日志。

我们仅为提供功能、维护连接及防止滥用处理必要数据。网络传输采用相应加密机制，但接收者仍可能保存已收到的数据。

## 你的选择与联系

你可以不启用互联网联机，也可以不配置第三方模型或语音服务。停止联机可终止后续游戏传输，但无法撤回其他参与者已经收到或缓存的内容。删除本机存档不会同步删除房主电脑或第三方服务上的副本。

如需了解、访问、更正或删除由官方服务处理的个人信息，或对本政策有疑问，请通过本页列出的隐私邮箱联系我们。我们会核实请求与相关数据的关联；第三方服务和其他玩家保存的数据，需要联系对应接收方处理。

本政策会随功能和服务变化更新。涉及数据用途、接收方等重要变更时，我们会更新本页，并通过相应功能入口提示。
